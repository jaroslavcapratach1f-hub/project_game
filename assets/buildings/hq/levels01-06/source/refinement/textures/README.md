# Texture provenance

`wood_diff.jpg`, `wood_nor_gl.jpg`, `wood_rough.jpg` are the 1K JPG diffuse,
OpenGL normal and roughness maps from Poly Haven's **Wood Table Worn**:
https://polyhaven.org/a/wood_table_worn

License: CC0 1.0 Universal (public domain dedication).
https://creativecommons.org/publicdomain/zero/1.0/
Authors credited by Poly Haven: Dimitrios Savva (photography), Rico Cilliers
(processing). Downloaded 2026-10-02. Materials embed these files in the GLB;
they require no runtime network request. Other small fabric/paint/roof maps
are generated by Textures.mjs.
